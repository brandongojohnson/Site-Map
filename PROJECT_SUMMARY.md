## 🐛 Troubleshooting

**Dev server won't start?**
- Kill port 5174: `lsof -i :5174 | kill -9`
- Run `npm run dev` again

**Icons not showing?**
- Verify lucide-react installed: `npm list lucide-react`
- Check import paths

**Styles not applying?**
- Ensure index.css imported in main.jsx
- Check Tailwind config content paths

**Build failing?**
- Delete node_modules: `rm -rf node_modules`
- Reinstall: `npm install`
- Rebuild: `npm run build`
